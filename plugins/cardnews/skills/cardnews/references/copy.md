# 글

카드 본문은 예요체. 짧게. 한 문장에 사실 하나.

## 기획서.md

- 이 편이 다루는 것 한 줄
- 장 구성
- 사실과 출처 URL, 확인한 날짜
- 카드에 안 쓴 것, 자료가 갈리는 것
- 사진·영상 출처와 라이선스
- 공식 영상이 없어 카메라 무브를 넣은 장
- 게시 전 허락이 필요한지

## 게시글문구.txt

인스타 캡션.

1. 첫 줄은 훅
2. 짧은 줄 몇 개
3. 확인할 사실은 `✔️`로
4. 주의할 점을 평서문으로
5. 몇 번째 장에 있는지
6. 저장, 댓글
7. 출처 한 줄
8. 해시태그 6–8개. 많이 달지 않는다

## X글.txt

짧게. 해시태그 남발 없음. 공식 URL 하나.

```
한 줄 훅
사실 두 줄.
https://공식주소
```

## 나레이션대본.txt

릴스 자막과 맞춘다. 소리 내어 읽으면 20–30초. 기본 렌더에는 목소리가 들어가지 않는다. `--tts` 또는 사용자가 준 음성 파일이 있을 때만 오디오가 생긴다.
