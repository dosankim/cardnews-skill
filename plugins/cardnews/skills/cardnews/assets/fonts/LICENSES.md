# 글꼴 라이선스

모두 SIL Open Font License 1.1 이다. 상업적으로 쓸 수 있고, 글꼴 파일만 따로 팔 수 없다.

| 파일 | 글꼴 | 받은 곳 |
|---|---|---|
| `Pretendard-*.woff2` | Pretendard | `pretendard@1.3.9` |
| `noto-serif-kr-korean-*.woff2` | Noto Serif KR | `@fontsource/noto-serif-kr` |
| `gowun-batang-korean-700-normal.woff2` | 고운바탕 | `@fontsource/gowun-batang` |
| `black-han-sans-korean-400-normal.woff2` | 검은고딕 | `@fontsource/black-han-sans` |
| `instrument-serif-latin-400-normal.woff2` | Instrument Serif | `@fontsource/instrument-serif` |
| `anton-latin-400-normal.woff2` | Anton | `@fontsource/anton` |
| `big-shoulders-display-latin-900-normal.woff2` | Big Shoulders Display | `@fontsource/big-shoulders-display` |
| `ibm-plex-mono-latin-500-normal.woff2` | IBM Plex Mono | `@fontsource/ibm-plex-mono` |

없는 파일은 `node scripts/fetch-fonts.mjs` 가 다시 받는다.
